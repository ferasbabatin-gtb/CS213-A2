note right of ByteStorage
  Size is fixed at construction and never resized.
  Memory passes MEMORY_SIZE (256, addresses 00..FF).
  CpuRegisters passes REGISTER_COUNT (16, registers 0..F).
  All cells start at 0, so unfilled memory is 0000,
  which is an invalid instruction.
  write() masks the value to 8 bits.
  read/write throw out_of_range on a bad index;
  Menu::readHex prevents that from happening.
  The destructor is protected: not meant to be
  deleted through a ByteStorage pointer.
end note

note right of Instruction
  Single source of truth for validation:
  - opcode 0, D, E, F invalid
  - 40RS: second nibble must be 0
  - AR0X: third nibble must be 0
  - C000: remaining nibbles must be 0
  parse(): reads 4 hex digits (upper or lowercase),
  ignores anything after them. false means invalid
  (fewer than 4 hex digits or a failed isValid check).
  Skipping comments and blank lines is NOT done here.
end note

note bottom of Cpu
  fetch(): returns false if pc > 0xFE, otherwise
  ir = Instruction(mem[pc]<<8 | mem[pc+1]); pc += 2
  decodeExecute(): if !ir.isValid() return INVALID_INSTRUCTION,
  else switch on ir.opcode()
  reset(startPc): pc = startPc, ir = 0, halted = false
  Rotate uses x % 8.
  lastOutput is the raw byte of the last store to FF.
  The CPU never decides how output looks.
  byteToFloat / floatToByte are used only by opAddFloat.
end note

note bottom of VoleMachine
  IMPORTANT: mem must be declared BEFORE cpu,
  because Cpu holds a reference to mem.

  isSkippableLine(): true for empty, whitespace-only,
  or lines whose first non-space character is ';'
  readProgramFile(): loops over every physical line,
  counting all of them so badLine matches the editor,
  skips lines using isSkippableLine, parses the rest
  with Instruction::parse, and rejects the whole
  program on the first invalid line
  loadProgram(): checks address is even and <= FE,
  calls readProgramFile, checks startAddr + 2*count <= 0x100,
  and only then writes memory, calls cpu.reset(startAddr)
  and sets programLoaded = true
  step(): if halted or no program loaded, returns STEP_HALTED.
  Otherwise fetch, decodeExecute, and if the status is
  SCREEN_OUTPUT convert cpu.getLastOutput() to text
  (ASCII, hex or both: decided here, in one place) and
  append it to screen. Maps ExecStatus to StepResult
  and stores it in lastStepResult.
  runAll(): loops step() until halt, error or maxSteps
  getIRString(): returns cpu.getIR().toString()
end note

note bottom of Menu
  Menu never sees Instruction.
  It displays the IR string from the machine
  and formats PC, memory and registers with toHex().
  showError() uses getLastStepResult() to explain
  why execution stopped (requirement 11).
end note
