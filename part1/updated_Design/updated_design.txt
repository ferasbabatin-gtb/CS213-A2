' ============================ Short notes ============================

note right of ExecStatus
  CPU's per-instruction result: ok, halted,
  screen write, invalid.
end note

note right of StepResult
  Returned by step and runAll; why execution
  stopped.
end note

note right of ByteStorage
  write() masks to 8 bits.
  read/write throw on bad index;
  isValidIndex is the non-throwing pre-check.
  Protected destructor.
end note

note right of Instruction
  isValid/parse are the single source of
  instruction validation. parse() reads 4 hex
  digits and ignores trailing text.
end note

note bottom of Cpu
  No mutable CpuRegisters reference leaves the CPU.
  setRegister returns false without writing when
  idx is invalid.
end note

note bottom of Screen
  bytes is raw; toString uses the stored format.
  formatBytes is the single renderer.
end note

note bottom of VoleMachine
  mem must be declared before cpu,
  because Cpu holds a reference to mem.
  runAll loops step() and returns the same
  StepResult, or STEP_LIMIT_REACHED if maxSteps
  is hit first.
  step() maps ExecStatus to StepResult and is
  the only consumer of ExecStatus.
end note

note bottom of Menu
  loadProgramFlow asks screen format once after
  a successful load, then calls printState to
  show the loaded memory. On any non-LOAD_OK
  result it calls showLoadError; runProgramFlow
  does not reload, and after a run it calls
  wantToExit, and on false performs the same
  load + format + printState sequence.
  runAllFlow and stepFlow both receive a
  StepResult and pass it to showError.
  print* methods are private; run() is the only
  public entry point.
end note
